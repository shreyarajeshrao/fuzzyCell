# Plot one pair's co-localisation by outcome

Shows, for one pair of cell types or groups, the per-image
co-localisation measured with the original labels (unweighted) and with
the bootstrap confidence weights (weighted), for each level of the
outcome. Each point is one image.

## Usage

``` r
plotMetricBoxplot(
  results,
  spe,
  fromType,
  toType,
  outcomeCol,
  metric = c("lfunction", "kontextual")
)
```

## Arguments

- results:

  Output of
  [`runColocalisationModels()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runColocalisationModels.md).

- spe:

  A `SummarizedExperiment` (e.g. a `SpatialExperiment`) with `imageID`
  and the outcome in `colData`.

- fromType, toType:

  The pair to show. An error is raised if the pair is not in the
  results; relative co-localisation (`"kontextual"`) only has pairs
  whose `toType` has a parent other than itself.

- outcomeCol:

  Name of the outcome column in `colData(spe)`.

- metric:

  The measure to plot: `"lfunction"` (co-localisation, the cross-type
  L-function) or `"kontextual"` (co-localisation relative to a parent
  population, the Kontextual measure).

## Value

An interactive plot, a `girafe` widget that needs the ggiraph package.
