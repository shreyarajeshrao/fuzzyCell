# Plot one cell type's proportion by outcome

Shows, for one cell type (or group), each image's proportion measured
with the original labels (unweighted) and with the bootstrap confidence
weights (weighted), for each level of the outcome. For the results of
[`runProportionsPipeline()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runProportionsPipeline.md)
the proportion is of all cells in the image; for the results of
[`runProportionsRelativeToParentPipeline()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runProportionsPipeline.md)
it is of the cells of the parent group. Each point is one image.

## Usage

``` r
plotProportionBoxplot(results, cellType, spe, outcomeCol)
```

## Arguments

- results:

  Output of
  [`runProportionsPipeline()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runProportionsPipeline.md)
  or
  [`runProportionsRelativeToParentPipeline()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runProportionsPipeline.md).

- cellType:

  The cell type to show: one of the `cellType` values in
  `results$proportions`. For
  [`runProportionsPipeline()`](https://shreyarajeshrao.github.io/fuzzyCell/reference/runProportionsPipeline.md)
  results this can also be one of the bootstrapped groups.

- spe:

  A `SummarizedExperiment` (e.g. a `SpatialExperiment`) with `imageID`
  and the outcome in `colData`.

- outcomeCol:

  Name of the outcome column in `colData(spe)`.

## Value

An interactive plot, a `girafe` widget that needs the ggiraph package.

## Examples

``` r
data(lungSubset)
data(lungCellTypeTree)
data(lungConfList)
res = runProportionsPipeline(lungSubset, lungCellTypeTree, lungConfList,
    outcomeCol = "disease_status", subject = "subject")
#> Computing unweighted proportions once (shared across all subtypes)...
#> Computing weighted proportions...
#> Fitting weighted models...
rel = runProportionsRelativeToParentPipeline(lungSubset, lungCellTypeTree,
    lungConfList, outcomeCol = "disease_status", subject = "subject")
#> Computing proportions relative to parent...
#> Fitting unweighted models...
#> Fitting weighted models...
if (requireNamespace("ggiraph", quietly = TRUE)) {
    plotProportionBoxplot(res, "Arteriole", lungSubset, "disease_status")
    plotProportionBoxplot(rel, "Arteriole", lungSubset, "disease_status")
}
```
